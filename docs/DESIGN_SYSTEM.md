# MiliAI 디자인 시스템

## 기준과 우선순위

1. 사용자가 가장 최근에 제공한 에셋, 화면 캡처, 브랜드 지침을 현재 디자인의 최우선 기준으로 사용한다.
2. 새 기준이 기존 규칙과 충돌하면 새 기준을 적용하고, 이전 자료는 `design-assets/archive/`에 보존한다.
3. 구현용 이미지는 `public/assets/`에, 원본 참고 자료와 근거는 `design-assets/archive/`에 보관한다.
4. 에셋을 받는 즉시 `docs/ASSET_ARCHIVE.md`에 출처, 수신일, 용도, 대체되는 이전 기준을 기록한다.

## 시각 토큰

| 항목 | 값 | 사용 규칙 |
| --- | --- | --- |
| Base | `#050806` | 전체 배경 |
| Surface | `#0B110D` | 패널과 콘텐츠 영역 |
| Signal lime | `#B7FF31` | Primary CTA, 현재 단계, 성공 신호 |
| Info blue | `#54C7FF` | 보조 상태와 AI 안내 |
| Success | `#4ED58A` | 완료·수령 상태 |
| Text primary | `#F4F7F4` | 제목과 핵심 정보 |
| Text muted | `white / 55%` | 설명과 메타정보 |

## 표면과 프레임

- 기본 패널은 낮은 대비의 얇은 경계와 그림자만 사용한다.
- 라임 모서리 프레임, 라임 외곽선, 글로우는 기본 상태에서 숨긴다.
- 포인터 hover 또는 키보드 focus-within에서만 프레임을 표시한다.
- 선택됨, 진행 중, 수료됨처럼 상태를 직접 나타내는 라임은 hover와 별개로 유지한다.
- 모달·미션 완료·경고처럼 사용자의 즉각적 주의가 필요한 화면은 예외적으로 프레임을 상시 표시할 수 있다.

## 인터랙션

- hover: 2px 상승, 라임 테두리, 코너 프레임, 약한 글로우
- focus: hover와 동등한 시각 피드백으로 키보드 사용성을 보장
- reduced motion: 반복 애니메이션을 정지하거나 최소화
- 모든 사용자 노출 문구는 한국어를 기본으로 하며, 고유한 미션 타이틀 등 승인된 영문만 사용한다.

## 테마와 학습 몰입도

- 모든 화면은 `#000000` 다크 모드를 기본값으로 사용한다.
- 우측 상단 토글에서만 라이트 모드로 전환할 수 있다. 라이트 캔버스는 `#F7F7F7`, 카드 표면은 `#FFFFFF`, LNB 표면은 `#FBFBF9`, 경계는 `#E4E6E1`을 사용한다.
- 라이트 모드의 본문은 `#1B1D1B`, 보조 텍스트는 `#6F736E`, 신호 라임은 `#A9F541`을 사용한다. 라임 텍스트는 가독성을 위해 `#6D9F17`로 낮춘다.
- 좌측 LNB와 상단 헤더는 배경을 반투명 처리해, 다크 화면에서는 다크 표면으로, 라이트 화면에서는 화이트 표면으로 보이게 한다.
- 라이트 모드 버튼은 하단 그림자를 사용하지 않는다. 상태 구분은 표면색(라임 / 블루 / 그린 / 앰버), 얇은 경계, 텍스트 위계로 처리하고 카드 그림자는 최소한으로 유지한다.
- 뱃지는 `AI 활용역량` / `AI 업무혁신역량` / `AI 사업창출역량`의 3개 역량군과 Lv1–Lv5 등급 체계를 따른다.

## 운영 규칙

- 파일명은 `YYYY-MM-DD--용도--설명.ext` 형식으로 명확히 만든다.
- 최신 에셋은 `ASSET_ARCHIVE.md`에서 `현재 기준`으로 표시한다.
- 이전 에셋은 삭제하지 않고 `대체됨`으로 표시한다.
- 새 화면은 이 문서의 토큰과 프레임 규칙을 먼저 적용한 뒤 개별 예외를 기록한다.
